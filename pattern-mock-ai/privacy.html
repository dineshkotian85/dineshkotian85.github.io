PatternMockAI — Privacy Policy

Effective date: 28 September 2026 [1]

Developer: Dinesh Kotian [1]

Contact email: dksoft.mobapps@gmail.com [1]

1. Overview

PatternMockAI is an educational application for creating practice questions and mock tests from textbook chapter images. The application is designed to process chapter images and OCR text primarily on the user's device [1].

2. Information stored on the device

PatternMockAI may store:

  • Chapter names and subjects [1].
  • Images selected or captured by the user for chapter processing [1].
  • OCR text generated from those images [1].
  • Generated questions, answers, test attempts and result statistics [1].
  • Application settings and reward/ad state [1].

These items are used to provide the application's core features. They are stored locally unless a feature or third-party service described below requires data to be transmitted [1].

3. Camera and photos

The app requests camera access when the user chooses to capture textbook pages. It requests photo/media access when the user chooses images from the device. Access is used for the selected app functionality and is not intended for unrelated collection [1].

4. OCR

OCR is performed using Google ML Kit libraries integrated into the Android application. The current implementation is intended to perform text recognition on-device. Users should review the current implementation and Google ML Kit documentation before publishing any statement that no image/text data leaves the device [1].

5. Advertising

PatternMockAI uses Google Mobile Ads (AdMob), including banner, native and rewarded/interstitial advertising where enabled. AdMob may collect and process device identifiers, diagnostics, advertising information and other data as described by Google. The exact data practices depend on the Google Mobile Ads SDK configuration and applicable consent choices [1].

6. Consent and personalized advertising

Where legally required, the app must obtain the appropriate consent before serving personalized advertising. The developer will configure Google's certified consent management solution/Privacy & messaging as applicable to users in the EEA, UK and Switzerland [1].

7. Data sharing

The developer does not intentionally sell users' textbook images, OCR text, questions or test results. Third-party advertising services may process data required for advertising, measurement, fraud prevention and related services [1].

8. Data deletion

Because the core chapter/question/test data is stored locally, users can remove it using the app's available delete/clear functions or by uninstalling the app. Advertising-related data may be retained or processed by Google according to Google's policies [1].

9. Children's privacy

PatternMockAI is not intended to be designed primarily for children. The developer must select the Play Console target audience accurately and comply with Google Play Families requirements if any child age group is selected [1].

10. Security

The developer takes reasonable measures to protect locally stored application data. No method of electronic storage or transmission is completely secure [1].

11. Changes

This policy may be updated when the application's functionality, SDKs or legal requirements change [1].
